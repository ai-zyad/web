# منصة تعليمية متكاملة - Flask Education Platform

منصة تعليمية كاملة مبنية باستخدام Python Flask مع تخزين JSON بدون قاعدة بيانات.

## المميزات

### للمستخدمين
- تسجيل دخول آمن مع تشفير كلمات المرور
- عرض الكورسات المتاحة
- مشاهدة الفيديوهات مع حماية متقدمة
- نظام إشعارات متكامل
- تصميم متجاوب يعمل على جميع الأجهزة

### للأدمن
- لوحة تحكم كاملة
- إدارة المستخدمين (إضافة، تفعيل، تعطيل)
- إدارة الكورسات (إضافة، تعديل، حذف)
- إدارة الأقسام والفيديوهات
- إدارة الاشتراكات
- إرسال إشعارات للمستخدمين
- مراقبة النشاطات (IP، الدولة، الجهاز)
- نظام جلسات متقدم مع موافقة على الأجهزة الجديدة

### الحماية
- منع أخذ لقطة الشاشة (PrintScreen)
- منع قائمة السياق (Right Click)
- منع F12 و Ctrl+Shift+I
- علامة مائية ديناميكية على الفيديوهات
- كشف فتح أدوات المطور
- تأمين روابط الفيديوهات
- نظام جلسات مع وقت انتهاء

## التثبيت

### المتطلبات
- Python 3.11 أو أحدث
- pip

### خطوات التثبيت

1. تثبيت المتطلبات:
```bash
pip install -r requirements.txt
```

2. تشغيل التطبيق:
```bash
python app.py
```

3. فتح المتصفح:
```
http://localhost:5000
```

## الاستخدام

### إضافة كورس جديد
1. تسجيل الدخول كأدمن
2. الذهاب إلى "إدارة الكورسات"
3. النقر على "إضافة كورس"
4. ملء البيانات وحفظ

### إضافة قسم وفيديوهات
1. الذهاب إلى "إدارة الكورسات"
2. النقر على "تعديل" للكورس
3. إضافة قسم جديد
4. إضافة فيديوهات للقسم

### إضافة مستخدم جديد
1. الذهاب إلى "إدارة المستخدمين"
2. النقر على "إضافة مستخدم"
3. ملء البيانات وحفظ

### تفعيل اشتراك
1. الذهاب إلى "الاشتراكات"
2. النقر على "إضافة اشتراك"
3. اختيار المستخدم والكورس

### جعل فيديو عاماً
1. الذهاب إلى "إدارة الكورسات"
2. النقر على "تعديل" للكورس
3. بجانب الفيديو، النقر على أيقونة القفل

## ملاحظات الأمان

- قم بتغيير `secret_key` في الإعدادات
- قم بتغيير كلمة مرور الأدمن الافتراضية
- استخدم HTTPS في الإنتاج
- قم بنسخ ملفات JSON احتياطياً
